# SFHIS Core 住院医嘱问题排查解决技能

## 一、技能执行强制规则

1. 严格匹配用户问题场景，仅回答文档内收录的住院药品故障问题，无匹配问题统一回复：当前问题暂无对应解决方案，请核查系统操作场景后重试。
2. 所有故障解决方案为系统标准操作流程，禁止删减、更改步骤，不得随意新增操作方式。
3. 用户提问口语化、场景近似的同义问题，统一按照对应标准答案回复。
4. 多故障问题同时咨询时，分点逐条对应解答，清晰展示每套解决方案步骤。

## 二、核心FAQ问答库

### Q1：药品医嘱无法停医嘱，系统提示：存在未领药的领药单记录，不能停医嘱！

同义提问：住院药品医嘱停不掉、停医嘱提示有未领药单、停医嘱失败存在未领药记录

故障原因：系统内该药品医嘱存在未完成的领药单记录，系统拦截停医嘱操作

标准解决方案：

1. 护士站操作：直接撤销系统提示对应的未完成领药单。
2. 版本特殊说明：2026年06月18日之前的系统旧版本，报错弹窗不展示领药单编号，需手动查询对应领药单后再撤销。
3. 撤销领药单完成后，即可正常执行停医嘱操作。

多附件资源列表：

1. 附件类型：完整操作讲解视频；附件ID：SF-DRUG-001-01；素材说明：药品停医嘱整体撤销流程完整演示视频
2. 附件类型：领药单撤销操作步骤截图；附件ID：SF-DRUG-001-03；素材说明：护士站撤销领药单分步操作截图

### Q2：领药单生成失败，系统提示：请求异常，库存不足！总量需XX，当前数量XX

同义提问：住院领药单生成不了、领药提示库存不足、药品库存不够无法生成领药单

故障原因：对应药房药品库存数量不足，无法满足医嘱领药需求

标准解决方案：联系药房管理人员，对对应药品进行补充库存，库存补齐后重新生成领药单即可。

### Q3：药品没有记上费，是否可以补费？如何处理？

同义提问：住院药品漏计费能补吗、药品没扣费怎么处理、医嘱发药未计费解决办法

核心结论：系统不支持直接手动补费，需按场景排查处理

标准排查及解决方案：

1. 优先核查发药状态：药品计费规则为发药自动计费，未计费大概率是未完成发药操作。
2. 核查药品库存：确认当前药房无对应药品库存的情况，排查实际使用的药品品类。
3. 跨药房排查：核查药品是否存放于其他药房，避免库存查询范围遗漏。
4. 场景一（药品正确、超量使用）：确认使用药品无误且超库存使用，先补充对应药品库存，再执行发药操作完成自动计费。
5. 场景二（药品选错）：实际使用药品与医嘱药品不符，直接作废原有医嘱，重新停止旧医嘱、新开正确药品医嘱即可。

## 三、异常兜底规则

1. 若用户无法确认故障场景、药品品类、库存情况，引导用户先核查医嘱信息、药房库存数据后再操作。
2. 所有操作均需在护士站、药房正规系统权限下执行，禁止违规后台操作。
3. 旧版本系统适配问题，优先以手动核查单据、撤销异常单据为核心处理方式。
