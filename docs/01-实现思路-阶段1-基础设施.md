## 一、业务目标与边界

本阶段实现系统**基础设施中的配置加载能力**，为后续所有模块（企微接入、聚合引擎、检索应答、Web UI）提供统一、安全的配置读取入口。

**目标**：

1. 支持从 `config.yaml` 读取配置，密钥（BotID/BotSecret）禁止硬编码；
2. 提供 `config.yaml.example` 模板入库，真实配置 gitignore；
3. 提供默认值兜底，保证缺失字段时服务仍可启动。

**边界**：本阶段只做配置加载与校验，不涉及企微接入、数据库等业务逻辑。

## 三、接口设计

### 3.1 `load_config(config_path: str | None = None) -> dict`

- **用途**：加载 `config.yaml` 配置，与默认配置合并。

- **参数**：`config_path` 配置文件路径；为 `None` 时按默认路径 `config.yaml` 查找。

- **返回**：合并后的配置字典。

- **说明**：文件不存在或解析失败时，使用默认配置并记录告警日志；密钥类字段优先取环境变量。

### 3.2 `get_config(key_path: str, default=None) -> Any`

- **用途**：按点分键路径读取配置值，如 `get_config("reply.prefix")`。

- **参数**：`key_path` 点分键路径；`default` 默认值。

- **返回**：配置值。

### 3.3 环境变量约定

| 环境变量               | 对应配置键              | 优先级            |
| ------------------ | ------------------ | -------------- |
| `WECOM_BOT_ID`     | `wecom.bot_id`     | 高于 config.yaml |
| `WECOM_BOT_SECRET` | `wecom.bot_secret` | 高于 config.yaml |

> 环境变量存在时覆盖配置文件中的值，保证密钥不入库。

## 四、关键代码逻辑（伪代码）

```python
# 默认配置常量
DEFAULT_CONFIG = {
    "wecom": {"bot_id": "", "bot_secret": ""},
    "reply": {"prefix": "[AI自动回复]：", "no_answer": "抱歉，暂时没有找到相关答案..."},
    "aggregate": {"window_seconds": 30, "max_queue": 3},
    "retriever": {"score_threshold": 0.3, "top_k": 5},
    "storage": {"db_path": "data/kb.db", "log_dir": "logs"},
    "web": {"host": "0.0.0.0", "port": 8080},
}

def load_config(config_path=None):
    config = deepcopy(DEFAULT_CONFIG)
    path = config_path or "config.yaml"
    try:
        with open(path, encoding="utf-8") as f:
            file_cfg = yaml.safe_load(f) or {}
        _deep_merge(config, file_cfg)
    except FileNotFoundError:
        logger.warning("配置文件不存在，使用默认配置: %s", path)
    except yaml.YAMLError as e:
        logger.error("配置文件解析失败，使用默认配置: %s", e)
    # 环境变量覆盖密钥
    if os.environ.get("WECOM_BOT_ID"):
        config["wecom"]["bot_id"] = os.environ["WECOM_BOT_ID"]
    if os.environ.get("WECOM_BOT_SECRET"):
        config["wecom"]["bot_secret"] = os.environ["WECOM_BOT_SECRET"]
    return config
```

## 六、验收标准

1. 存在 `config.yaml.example` 模板，覆盖全部配置项且不含真实密钥；
2. `load_config` 在配置文件缺失时可用默认配置启动不报错；
3. 环境变量可覆盖 `wecom.bot_id` / `wecom.bot_secret`；
4. `get_config` 支持点分键路径读取；
5. 代码符合规范：中文注释、try/except 指定异常类型、单函数 ≤ 50 行。
