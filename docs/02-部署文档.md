# 02-部署文档

> 版本：v0.1（收尾阶段）
> 说明：本文档面向部署人员，包含环境要求、依赖安装、配置说明、企业微信配置、启动方式与故障排查。

***

## 一、环境要求

| 项目       | 要求                                    |
| -------- | ------------------------------------- |
| 操作系统     | Linux / macOS / Windows（开发验证以 Linux 为主）   |
| Python   | 3.11+                                  |
| 内存       | 最低 256 MB（轻量级单进程，知识库规模增大时按需扩容）       |
| 磁盘       | 数据库 + 知识库仓库占用，典型场景 < 1 GB           |
| 网络       | 可访问企微长连接地址 `wss://openws.work.weixin.qq.com` |
| 其他       | 可选安装 `git`（使用 `kb.repo_url` 远程同步时必需）     |

> 纯本地部署，无需数据库服务、无需 Redis/消息队列；SQLite 单文件存储于 `data/kb.db`。

***

## 二、依赖安装

```bash
# 建议创建虚拟环境
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate

# 安装依赖（仅 6 个包，见 requirements.txt）
pip install -r requirements.txt
```

依赖清单：`fastapi`、`uvicorn`、`httpx`、`pyyaml`、`jinja2`、`websockets`。

***

## 三、配置文件说明

1. 复制模板并填写：

```bash
cp config.yaml.example config.yaml
```

2. 密钥建议用环境变量注入（优先级高于配置文件）：

```bash
export WECOM_BOT_ID="你的BotID"
export WECOM_BOT_SECRET="你的Secret"
```

3. `config.yaml` 字段说明（完整模板见 `config.yaml.example`）：

| 字段                        | 说明                                        | 默认值                              |
| ------------------------- | ----------------------------------------- | -------------------------------- |
| `wecom.bot_id`            | 智能机器人 BotID（建议环境变量 WECOM_BOT_ID）         | 空                               |
| `wecom.bot_secret`        | 智能机器人 Secret（建议环境变量 WECOM_BOT_SECRET）     | 空                               |
| `wecom.ws_url`            | 长连接 WebSocket 地址（官方固定）                    | `wss://openws.work.weixin.qq.com` |
| `wecom.heartbeat_seconds` | 心跳间隔（秒）                                   | 30                               |
| `wecom.reconnect_max_seconds` | 断线重连退避封顶（秒）                          | 30                               |
| `wecom.dedup_cache_size`  | msgid 去重缓存上限                              | 10000                            |
| `reply.prefix`            | 回复前缀                                      | `[AI自动回复]：`                     |
| `reply.no_answer`         | 无结果话术                                    | 见模板                             |
| `aggregate.window_seconds` | 群聊多消息聚合时间窗（秒）                          | 30                               |
| `aggregate.max_queue`     | 单用户与机器人同时在途消息上限（企微硬限制 3）                 | 3                                |
| `aggregate.mention_targets` | @ 触发目标列表，为空时回退到 bot_id                  | `[]`                             |
| `retriever.score_threshold` | FTS5 检索置信度阈值，低于视为无结果                 | 0.3                              |
| `retriever.top_k`         | 召回候选条数                                   | 5                                |
| `kb.repo_url`             | Git 仓库地址，为空则用本地目录                        | 空                               |
| `kb.repo_branch`          | 同步分支                                      | main                             |
| `kb.repo_path`            | 本地 MD 文档目录（repo_url 为空时使用）               | 空                               |
| `kb.work_dir`             | 仓库克隆/工作目录                               | `data/kb_repo`                   |
| `kb.chunk_size`           | 切分片段字符数                                  | 500                              |
| `kb.chunk_overlap`        | 片段尾部重叠字符数                                | 50                               |
| `kb.include_patterns`     | 入库文件匹配模式                                | `["*.md"]`                       |
| `kb.exclude_patterns`     | 排除文件（按 basename 匹配）                     | `["README.md"]`                  |
| `storage.db_path`         | SQLite 数据库文件路径                            | `data/kb.db`                     |
| `storage.log_dir`         | 日志目录                                      | `logs`                           |
| `web.host` / `web.port`   | Web 服务监听地址与端口                            | `0.0.0.0` / `8080`               |

> `config.yaml` 已在 `.gitignore` 中，禁止提交含密钥的真实配置。

### 3.1 动态配置覆盖

除 `config.yaml` 外，系统参数页（`GET /config`）保存的配置写入 SQLite `sys_config` 表，作为**运行时覆盖层**叠加在 `config.yaml` 之上。启动顺序为：`load_config → init_db → overlay_db`，因此 `sys_config` 中的值优先级最高。**保存后需重启进程生效**（MVP 未做热更新）。

## 四、企业微信智能机器人配置

> 以企微官方文档为准：https://developer.work.weixin.qq.com/document/62155

1. **创建智能机器人**：在企业微信管理后台创建「智能机器人」，获取 `BotID`（即回调中的 `aibotid`）与 `Secret`。具体创建入口与权限要求以官方文档为准。

2. **长连接订阅**：本系统通过 WebSocket 长连接接收回调，无需配置公网回调 URL。启动后由 `src/wecom/callback.py` 自动发起 `aibot_subscribe` 订阅并维持心跳。

3. **权限要点**：
   - 机器人创建者为企业超级管理员时，`from.userid` 为明文；否则为加密 userid（系统按原始值处理，不依赖明文）。
   - 单用户与机器人同时在途消息最多 3 条（企微硬限制），系统已通过信号量控制。

> ⚠️ 上述字段与流程已在代码中按官方字段实现，创建入口层级以企微后台实际界面为准，如有变动以官方文档为准。

## 五、启动方式

源码入口为 `src/main.py`，因模块采用顶层导入，需在 `src/` 目录下启动。

### 5.1 前台运行

```bash
cd src
uvicorn main:app --host 0.0.0.0 --port 8080
```

或：

```bash
cd src
python -m main
```

### 5.2 后台运行（Linux）

```bash
cd src
nohup uvicorn main:app --host 0.0.0.0 --port 8080 > ../logs/web.log 2>&1 &
```

> 建议生产环境使用 systemd 或 supervisor 管理进程，此处给出 nohup 作为最简示例。

### 5.3 验证

- Web 界面：浏览器打开 `http://<服务器IP>:8080/`，可见「概览」页。
- 未配置 `bot_id/bot_secret` 时仅启动 Web，日志会提示"仅启动 Web 界面"，不影响界面访问。
- 配置凭据后启动，日志出现"企微长连接已启动"即表示订阅成功。

## 六、内网穿透（如需外网回调）

本系统采用长连接接收，正常运行**无需内网穿透**。若后续扩展被动回复 `response_url` 等需公网可达的场景，可选用 frp / ngrok / 花生壳等工具，将服务器端口暴露后按官网配置。当前阶段不依赖公网回调。

## 七、常见故障排查

| 现象                 | 排查要点                                      |
| ------------------ | ----------------------------------------- |
| 长连接无法建立/反复重连    | 确认 `bot_id`/`bot_secret` 正确、网络可访问 `wss://openws.work.weixin.qq.com` |
| 日志提示"仅启动 Web 界面" | 未配置凭据，属正常现象，不影响 Web；补配置后重启即可             |
| 知识检索无结果           | 确认已通过「知识库」页触发同步、`kb.repo_url`/`repo_path` 配置正确 |
| 同步报 Git 错误        | 确认 `git` 已安装、仓库地址可访问、分支名正确                |
| Web 页面打不开          | 确认端口未占用、防火墙放行 `web.port`                  |
| 配置保存不生效          | 动态配置需重启进程后生效                              |

日志查看：日志输出到标准输出（`nohup` 方式重定向至 `logs/web.log`），格式为 `时间 | 级别 | 模块 | 消息`。
